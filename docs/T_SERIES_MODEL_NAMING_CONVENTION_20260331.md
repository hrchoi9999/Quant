# T-series Model Naming Convention (2026-03-31)

## 내부 개발용 기본 명칭
- 주식: `T-STOCK-V01`
- ETF: `T-ETF-V01`

## 세부 관리 명칭
- `T-STOCK-V01-S1`
- `T-STOCK-V01-S2`
- `T-ETF-V01-S1`
- `T-ETF-V01-S2`

## 해석
- `S1`: 하위 그룹에서 상위 중간 그룹으로 승격될 가능성을 탐지하는 단계
- `S2`: 상위 중간 그룹에서 최상위 그룹으로 승격될 가능성을 탐지하는 단계

## 현재 적용 상태
- ETF 운영형 V1은 `T-ETF-V01`로 관리한다.
- ETF 1단계 모델은 `T-ETF-V01-S1`로 관리한다.
- ETF 2단계 모델은 `T-ETF-V01-S2`로 관리한다.
- 주식 운영형 V1은 향후 `T-STOCK-V01`로 같은 방식으로 정리한다.

## 사용 원칙
- Quant 내부 문서/스크립트/산출물 관리에는 위 코드명을 사용한다.
- QS 전달 시에는 별도 합의한 설명명으로 변환한다.
