# S3 Sensitivity Analysis Plan

## 목적

현재 `S3`는 `T3`, `T10_ex_T3` 기준 정확도가 아주 높다고 보기 어렵다.

- `T3 정확도`: `6.02%`
- `T10_ex_T3 정확도`: `4.85%`

따라서 `S3` 재설계에 바로 들어가기 전에, 현재 점수 구조의 어떤 축이 정확도와 포트폴리오 성과에 가장 큰 영향을 주는지 먼저 확인해야 한다.

이번 민감도 분석의 목적은 아래 3가지를 분리해서 보는 것이다.

1. 단기 모멘텀 비중을 줄이거나 늘리면 정확도가 어떻게 변하는가
2. 실적 가속 비중을 강화하면 `T3`, `T10_ex_T3` 정확도가 개선되는가
3. 장기 추세 비중을 높이면 수익률, MDD, 정확도 중 무엇이 좋아지는가


## 현재 S3 구조

현재 연구용 `S3` 점수는 대략 아래 구조를 가진다.

- 펀더멘털 수준: `0.30`
- 실적 가속: `0.20`
- 단기 모멘텀 블록: `0.40`
  - `mom20`: `0.25`
  - `vol_ratio_20`: `0.10`
  - `breakout60`: `0.05`
- 장기 추세: `0.10`

즉 현재 구조는

- 단기 모멘텀 계열 비중이 가장 크고
- 실적 가속과 장기 추세 비중은 상대적으로 작다

로 요약할 수 있다.


## Top3 Entry 연구와의 차이

`Top3 entry` 연구에서는 아래 신호가 상대적으로 더 유의했다.

- `revenue_yoy`
- `op_income_yoy`
- `rev_delta_3m`
- `op_delta_3m`
- `ma_stack_gap`

반면 아래 신호는 약하거나 불리했다.

- `mom20`
- `dist_ma60`
- `breakout60`

즉 현재 `S3`는

- 단기 모멘텀 계열을 상대적으로 강하게 쓰고 있고
- 실제 `Top3 entry`에 유효했던 실적 가속 및 장기 추세 정렬을 상대적으로 약하게 쓰고 있을 가능성이 있다.


## 왜 민감도 분석이 먼저 필요한가

현재 단계에서 바로 점수식을 바꾸면 다음 문제가 생긴다.

- 어떤 축이 진짜 문제인지 모른다
- 어느 정도까지 줄이거나 늘려야 하는지 알 수 없다
- 정확도 개선과 포트폴리오 성과 개선이 서로 충돌할 수 있다

그래서 먼저

- 단기 모멘텀
- 실적 가속
- 장기 추세

세 축을 독립적으로 흔들어 보고,

- `T3 정확도`
- `T10_ex_T3 정확도`
- `3M / 6M / 1Y` 성과
- `MDD`

가 어떻게 변하는지 보는 게 필요하다.


## 분석 축

### 1. 단기 모멘텀 비중

목표:

- `mom20`, `vol_ratio_20`, `breakout60` 비중을 줄이거나 늘렸을 때
- 현재 `S3`의 정확도가 개선되는지 확인

가설:

- 현재 `S3`는 단기 모멘텀 계열 비중이 과할 수 있다
- 이 비중을 낮추면 `T3`, `T10_ex_T3` 정확도가 개선될 가능성이 있다


### 2. 실적 가속 비중

목표:

- `fund_accel_score`
- 필요하면 `rev_delta_3m`, `op_delta_3m`

계열의 비중을 높였을 때 정확도가 개선되는지 확인

가설:

- `Top3 entry` 분석상 실적 가속은 분명히 유효한 축이다
- 따라서 `S3`에서도 실적 가속 비중을 강화하면 미래 상위 그룹 적중률이 올라갈 가능성이 있다


### 3. 장기 추세 비중

목표:

- `ma60 > ma120`
- `ma60_slope > 0`
- 필요하면 `ma_stack_gap`

같은 장기 추세 정렬 신호 비중을 높였을 때 효과 확인

가설:

- `Top3 entry`는 장기 추세 정렬이 있을 때 더 잘 나타났다
- 따라서 단순 보너스 수준인 현재 구조를 강화하면 정확도와 MDD가 같이 개선될 가능성이 있다


## 추천 분석 순서

### 1단계: 단일 축 민감도

아래 3가지를 각각 따로 본다.

1. 단기 모멘텀 비중만 변화
2. 실적 가속 비중만 변화
3. 장기 추세 비중만 변화

이 단계에서는 어떤 축이 가장 큰 설명력을 가지는지 파악하는 것이 목적이다.


### 2단계: 상호작용 민감도

단일 축에서 유망한 방향이 보이면 아래 조합을 본다.

- `단기 모멘텀 감소 + 실적 가속 증가`
- `단기 모멘텀 감소 + 장기 추세 증가`
- `실적 가속 증가 + 장기 추세 증가`


### 3단계: 최종 후보 선택

아래 우선순위로 최종 후보를 고른다.

1. `T3 정확도`
2. `T10_ex_T3 정확도`
3. `3M / 6M / 1Y` 포트폴리오 성과
4. `MDD`


## 추천 테스트 범위

### 단기 모멘텀 블록

현재 비중: `0.40`

테스트 후보:

- `0.15`
- `0.25`
- `0.35`
- `0.45`


### 실적 가속 블록

현재 비중: `0.20`

테스트 후보:

- `0.15`
- `0.25`
- `0.35`


### 장기 추세 블록

현재 비중: `0.10`

테스트 후보:

- `0.05`
- `0.10`
- `0.20`
- `0.30`


## 판단 기준

민감도 분석의 평가는 아래 순서로 본다.

1. `T3 정확도`가 올라가는가
2. `T10_ex_T3 정확도`가 같이 올라가는가
3. `3M / 6M / 1Y` 포트폴리오 수익률이 유지되거나 개선되는가
4. `MDD`가 과도하게 나빠지지 않는가


## 현재 결론

현재는 `S3`를 바로 재설계하기보다, 먼저 아래 3축 민감도 분석을 하는 것이 맞다.

- 단기 모멘텀 비중
- 실적 가속 비중
- 장기 추세 비중

그 결과를 바탕으로

- `S3 개선안 V1`
- `S3 개선안 V2`

같은 조합형 후보를 설계하는 것이 가장 효율적이다.
